0.5.0：隔离执行 + 可核验的失败解释

## 这个版本是什么

一个单机、单用户的执行底座：跑不可信程序，返回**判定**与**产物清单**；再让分析层解释失败，
每条结论都能指回某一行证据。

## 沙箱本体

- 隔离执行：user / mount / pid / net namespaces、PID 1 init、seccomp 基线策略、cgroup v2 限额
  （cpu / memory / pids / tmpfs 字节与 inode 配额）。
- 判定语义：`verdict` 与 `summary` 分离；**产物未交付绝不算成功**；清理失败如实上报（退出码 `125`）。
- 产物交付：staging + `renameat2(RENAME_EXCHANGE)` 原子发布；跨文件系统 copy-then-exchange；
  `durable` / `retained_previous_path` 单独成事实；运行目录写 `checksums.json`（五个文件的 sha256）。
- 持久会话与批处理；Python SDK 与 `sandbox serve_session` 控制通道（`proto/session_v1.proto`）。

## 分析层（`sandbox_ai`，纯 Python、零依赖）

- 引用契约：模型只回 `{id, line}`，原文由程序解析——**没有伪造引用文本的通道**。
- 检索：BM25（可选向量 + RRF）+ 可选 rerank；被问题点名的文件强制进上下文；统计量按语料代际缓存。
- 工具循环：`read_evidence` / `read_output` / `search_history` / `propose_verification`，有界调用。
- 假设状态：可选 `hypothesis_updates`，"支持/反驳"必须引用验证运行的证据，写库可见。
- 受控验证：操作者登记模板（digest 锁定、`${run_dir}` 占位符、白名单替换），回执一律
  `executed_not_automatically_confirmed`。
- 导入完整性：校验 `checksums.json`；不匹配**拒绝导入**，缺文件记 `partial`，无校验和记 `unverified`。

## 命令行

- `sandbox run -- [选项] -- COMMAND...` 一行跑；`--summary` 六行人话；`--quiet` 关 stderr 日志。
- `sandbox doctor`（可用启动模式）、`inspect`、`cancel`、`cleanup`、`prune --keep/--older-than/--dry-run`。
- `sandbox help <cmd>`；`sandbox-ai`：`import` / `analyze` / `explain` / `verify` / `stats` / `demo`。
- 根目录 `action.yml`：GitHub composite action，按 `verdict` 决定 CI 成败。

## 未验证 / 边界

- **GitHub 托管 runner 上的 user 级委派拿不到 cpu/memory/pids**：action 会显式降级到诊断后端
  （报告 `isolated=false`）。要真隔离用系统级委派，命令见 `docs/CI.md`。
- 跨发行版/内核、崩溃与掉电恢复、长时间压力、真实恶意代码：未验证。
- 语义充分性只有自评指标（未与人工标注对齐）；4/4 的引用通过率是**样本内**结果。
- `checksums.json` 是自证的：防误改，不防伪造（无签名）。
- 明确不做：多租户/鉴权、seccomp 策略 DSL、守护进程化、ANN、分布式。

## 安装

```bash
# 源码
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build --parallel
bash tools/install.sh          # 装到 ~/.local，含 sandbox-ai

# 预编译包（本 Release 附件）
tar -xzf linux-sandbox-0.5.0-linux-x86_64.tar.gz -C /opt
/opt/linux-sandbox-0.5.0-linux-x86_64/bin/sandbox doctor

# 只要分析层
pip install .                  # 或 pip install ".[sdk]"
```

从 `docs/QUICKSTART.md` 开始；字段兼容承诺见 `docs/CONTRACT.md`；安全边界见 `docs/THREAT_MODEL.md`。
